# 真实路由指导的预取专家重构与联合训练

日期：2026-10-01。本文提出一种研究设计：prerouter 提前一个 token 为各目标 MoE 层选择并预取专家，在目标层到达后，由原生 router 指导可微 substitutor 在预取集合内重分配贡献并补偿输出，以重构或端到端蒸馏损失联合训练两个模块，实现 fallback-free 执行。文中的可学习结构和训练路线是待验证方案；相关工作依据见[专家替代与预取调研](moe_expert_substitution_prefetch.md)。

CommitMoE 是最直接的执行范式基线：预测集合决定实际执行集合，真实路由参与后到的权重调整。这里的研究重点是各目标层的一 token lookahead、专家功能关系驱动的可微补偿，以及由补偿后输出质量反过来优化预取集合。

## 1. 问题定义：提前确定可用集合，随后重构真实路由的输出

这里有两个不同时间点的决策。

1. **预取时刻：** 只有前一 token 已产生的表示 $z$，prefetch router 产生 $p_\theta$，为下一 token 的目标层选择专家集合 $P$ 并发起加载。
2. **执行时刻：** 得到目标层输入 $x$ 和原生 router 的完整分数 $q$。此时可以知道原生选择 $A$ 及其实际混合权重 $g$，但希望只执行已经预取的专家。

因此，核心是一个两阶段问题：

$$
P=\operatorname{TopK}_{K_p}(p_\theta(z)),\qquad
\alpha=F_\phi(p_\theta,q,P),\qquad
\hat y=\sum_{j\in P}\alpha_jE_j(x).
$$

目标输出为：

$$
y^\star=\sum_{i\in A}g_iE_i(x).
$$

原生共享专家单独执行。本节先假设 $P$ 中的权重已按时就绪；系统实验再用真正 ready 的集合检验。预取完成以前，不能把预测选中当成可执行。

### 1.1 区分预取数与执行数

| 设置 | 原生 router 能指导什么 |
|---|---|
| $K_p=K_{\mathrm{exec}}$，执行所有预取专家 | 主要决定各专家的权重；权重为零可进一步跳过 |
| $K_p>K_{\mathrm{exec}}$ | 可以在预取集合内重新选择子集，再决定权重；多出一次离散选择 |
| fallback-free 执行 | 真实路由只指导预取集合内的选择和权重；预测遗漏不触发集合外原专家补载 |

建议第一版固定 $K_p$，执行其所有非零加权专家，集中验证重构能力。这样输出校正的收益不会与新增预取预算混淆。

初始比较可取 $K_p=K_0$，其中 $K_0$ 是原生 top-k；随后扫描较小预算来测试功能冗余可压缩到什么程度。即使 $K_p=K_0$，替代感知选择仍有价值：提前一 token 时不知道未来的精确集合，所选专家需要覆盖多种可能的未来需求。

### 1.2 路由分布、选择分数与实际权重分别记录

对 softmax gate，可以用归一化的 $p,q$ 表达问题；对 sigmoid、带 correction bias 或分组限制的 gate，必须保留三项原生语义：

- 选择专家时使用的分数；
- 原生约束下得到的专家 ID；
- 真正乘到 expert output 上的权重 $g_i$，含归一化和 routed scaling。

目标 $y^\star$ 使用原模型实际选中的稀疏权重，不是把全部专家按完整分布 $q$ 加权。完整 $q$ 则可作为重构模块的输入，提供原 top-k 之外的信息。

### 1.3 原生路由是真实的局部决策，完整模型输出是另一层参考

若前面几层已经使用替代，当前 $x$ 已改变。此时原生 router 给出的 $q(x)$ 是当前轨迹上的真实路由，不一定等于完整原模型在其自身轨迹上的路由。

局部训练可在同一个 $x$ 上比较原生 MoE 与替代 MoE；全模型质量评估仍需比较独立原模型的 logits 和任务结果。不能把局部重构好直接视为整条生成轨迹恢复。

### 1.4 提前一个 token 的因果时间线

令 $t$ 表示当前处理的输入 token 位置，$l$ 表示目标 MoE 层。一种直接的实现是同层跨 token 预测：

$$
p_{t,l}=p_{\theta,l}(z_{t-1,l}),\qquad
P_{t,l}=\operatorname{TopK}_{K_p}(p_{t,l}),
$$

$$
(q_{t,l},A_{t,l},g_{t,l})=\operatorname{Router}_l(x_{t,l}),\qquad
\alpha_{t,l}=F_{\phi,l}(p_{t,l},q_{t,l},P_{t,l},u_{t,l}).
$$

$z_{t-1,l}$ 是处理前一 token 时在该层已可获得的表示；$u_{t,l}$ 是当前目标层的廉价条件特征。具体时间顺序为：

| 时刻 | 已知信息与动作 |
|---|---|
| 处理 token $t-1$ 的层 $l$ | 计算 $p_{t,l}$，固定 $P_{t,l}$，发起对应专家的预取 |
| token $t-1$ 的后续层与 token $t$ 的前序层 | 与这些计算重叠完成加载，按实际队列和缓存容量调度 |
| 处理 token $t$ 的层 $l$ | 计算真实 router；substitutor 将 $A_{t,l}$ 的贡献映射到 $P_{t,l}$ |
| 专家执行 | 仅执行选定的预取专家并聚合，记录权重到位等待与补偿开销 |

预测发出时，下一输入 token 的采样结果通常尚未产生；训练时也只能把它的路由和专家输出作为标签，不能作为 prerouter 输入。teacher-forcing 训练需明确将预测源位置 $t-1$ 与目标位置 $t$ 对齐，避免同时可见整段序列造成标签泄漏。若在前一 token 末层才统一预测各层，浅层与深层的加载窗口会不同，应作为另一种时间线配置测量。

同层跨 token 预测的窗口大致覆盖前一 token 的剩余计算和当前 token 到目标层前的计算。它可能比提前一层提供更长搬运时间，同时也需要预测跨 token 的需求变化。各层预取还共享传输带宽和暂存空间；提前发出不等于全部专家按时到位。fallback-free 的约束是执行时不因预测 miss 补载原专家，已承诺集合迟到时仍可能等待。

CommitMoE 的主时间线是同 token 提前一个 MoE 层：$(t,l-1)\to(t,l)$；边界采用 $(t-1,L)\to(t,1)$，其中 $L$ 表示最后一个 MoE 层。两者都是沿执行顺序预测下一次 MoE 调用。边界预测发出时，前一 token 已推进到末层，其窗口仅覆盖末层到下一 token 首层之间的计算。本方案的 $(t-1,l)\to(t,l)$ 则为同一目标层提前一个 token。应分别比较原论文时间线和使用同一 token 提前量的补偿基线，以分辨收益来自预测窗口还是 substitutor。

## 2. 建模目标：学习一个能重构原输出的预取集合

仅训练 $D_{\mathrm{KL}}(q\Vert p_\theta)$，主要鼓励预测原专家 ID 和分布。联合训练则可以更直接地优化：

$$
\min_{\theta,\phi}
\mathbb E\left[
D\!\left(
\sum_{i\in A}g_iE_i(x),
\sum_{j\in P_\theta(z)}\alpha_{\phi,j}(p_\theta,q,P_\theta)E_j(x)
\right)
\right].
$$

这允许一个有用的情况：预测集合与原集合不完全相同，但它包含的专家足以准确重构原输出。相反，即使 top-k recall 相同，不同预测集合的可补偿性也可能差很多。

可以把理想目标理解为：

$$
\min_\theta\mathbb E\left[
\min_{\alpha:\operatorname{supp}(\alpha)\subseteq P_\theta(z)}
D(y^\star,Y_{P_\theta}\alpha)
\right],
$$

其中 $Y_P=[E_j(x)]_{j\in P}$。可学习模块 $F_\phi$ 的作用，是在推理时仅凭廉价特征近似求出内层的好权重。

### 2.1 两组概率提供路由证据，功能关系决定如何补偿

相同的 $p,q$ 并不能唯一确定最优替代权重。例如原专家输出是 $(1,0)$，唯一预取专家输出是 $(0,1)$，任何标量权重都不能重构原输出；如果预取专家输出改为 $(0.5,0)$，权重 2 就能精确重构。两种情况可以具有相同的路由概率。

因此，重构模块至少需要通过训练参数或输入特征编码专家身份及功能关系。可以采用：

- 每层专家 ID embedding；
- 校准得到的方向性标量和重构损失；
- 由较早表示 $z$ 或当前表示 $x$ 提取的低维条件特征。

只输入 $p,q$ 的小网络也可以作为基线：如果保留专家维度的固定身份，它可以隐式学习关系，但需要足够的输出监督。对排序后概率进行匿名处理则会丢失专家身份。

### 2.2 专家的价值取决于已经选择了谁

考虑一个仅用于说明功能冗余的二维例子。原生选择三个专家，当前 token 上：

$$
g_a=0.45,\quad g_b=0.40,\quad g_c=0.15,\qquad
E_a(x)=(1,0),\quad E_b(x)=(1.1,0),\quad E_c(x)=(0,1).
$$

目标输出为：

$$
y^\star=0.45E_a+0.40E_b+0.15E_c=(0.89,0.15).
$$

假设预算为两个专家，按真实分数取最高的 $\{a,b\}$，无论如何调整两个标量系数，第二维都为零；最小平方误差至少为 $0.15^2=0.0225$。选择 $\{a,c\}$，利用 $E_b=1.1E_a$，则可以：

$$
\hat y=(0.45+1.1\times0.40)E_a+0.15E_c=y^\star.
$$

因此，高分的 $b$ 在 $a$ 已选中后可能增加很少的重构能力；低分的 $c$ 却提供了缺失的方向。补偿权重 $(0.89,0.15)$ 的和为 1.04，说明标量投影会改变权重总和。若强制和为 1，本例便无法精确恢复目标。

这个构造例说明**集合价值包含专家之间的冗余与互补**，并不证明实际模型处处存在这样的关系。真实模型中需验证关系是否在当前 token、预测失误分布和量化精度下仍成立。简单地改一个单专家重要性分数，也未必能充分表达这种依赖已选集合的价值。

### 2.3 早期选择优化预期重构，后到路由适配实际需求

在预取时刻，prerouter 无法看到当前 $q$ 和专家输出。理想集合目标可以更准确地写成：

$$
P^\star(z)=
\arg\min_{P:\lvert P\rvert=K_p}
\mathbb E\left[
\left.
\min_{\alpha\in\mathcal C(P)}
\|y^\star-Y_P\alpha\|_2^2
\right|z
\right].
$$

这里 $\mathcal C(P)$ 指定支持集合与系数约束。早期集合应在给定 $z$ 的多种可能未来上取得较好的预期重构；执行时的 $q$ 则指导它适配已经发生的具体需求。内层最优权重是离线 oracle，实际部署用轻量 $F_\phi$ 估计。

因此，prerouter 的输出可以解释为用于选择重构基底的优先级，而不必严格等同于未来原 router 的概率分布。真实路由仍提供有价值的初始化和辅助监督；核心训练信号是最终选中集合经补偿后的输出误差。只有在当前预算下输出足够可表达、且训练能优化集合成员时，这个目标才可能优于路由模仿。

### 2.4 选择与补偿的耦合程度

需要分别观察“候选从哪里来”“保留集合如何确定”“固定集合后怎样补偿”：

| 工作 | 保留集合或可用集合的来源 | 替代/补偿关系参与的决策 |
|---|---|---|
| BuddyMoE | 当前驻留状态约束候选；原路由与门控决定哪些请求可替代 | 共激活 buddy 排名参与驻留候选筛选，尚未以补偿后输出误差联合优化预取集合 |
| ExFold | Prefill 按 score×norm；decode 按 batch 累计贡献选池 | 标量重构损失决定省略专家映射到哪个保留专家 |
| CommitMoE | 以路由 KL 训练的 predictor 决定预取集合 | OWA 在既定集合内按交集和权重质量调整，未用其输出误差训练集合选择 |
| LDA | 配合给定的 top-k/top-p 等稀疏路由策略 | 对所选策略的聚合输出做统计对齐 |
| SERE | 原生 top-S 并集构成 primary；相似度阈值决定其余专家是否保留 | 相似度参与 critical 专家的保留判断，具有局部耦合 |

ExFold 的 Eq. 5 已将保留集合、映射和投影写入统一输出近似目标；其实际选择器 Eq. 10–11 使用贡献排序，投影损失在集合确定后的映射阶段使用。因此，可研究的具体推进是**让可执行的集合选择算法直接使用补偿后的误差或其可靠估计**，并把这个信号传给提前一个 token 的预取器。上述判断限定于已核验的方法，不能直接推广为整个剪枝领域都没有选择与补偿的联合优化。

## 3. 推荐模块：保留命中贡献，对遗漏贡献进行可学习分配

定义：

$$
C=A\cap P,\qquad M=A\setminus P.
$$

对于命中专家 $j\in C$，先保留其原生贡献 $g_jE_j(x)$。对每个遗漏专家 $i\in M$，学习它在预取集合上的分配：

$$
T_{ij}
=\frac{\exp s_\phi(i,j;p_\theta,q,u)}
{\sum_{b\in P}\exp s_\phi(i,b;p_\theta,q,u)},
\qquad j\in P.
$$

这里 $u$ 是可选的低维 token 特征。最终权重定义为：

$$
\boxed{
\alpha_j=
\mathbf1_{j\in C}g_j+
\sum_{i\in M}g_iT_{ij}c_{ij},
\qquad j\in P
}
$$

相应输出为：

$$
\hat y=\sum_{j\in P}\alpha_jE_j(x).
$$

这个式子将真实 router 的指导落实为三件事：哪些原贡献已经命中、哪些贡献缺失、每份缺失贡献需要多少补偿。prefetch 分布则提供早期判断与当前判断的差异，帮助识别本次预测失误的类型。

### 3.1 三个递进版本

| 版本 | $T_{ij}$ | $c_{ij}$ | 用途 |
|---|---|---|---|
| A：质量重分配 | 学习式 row-softmax | 固定为 1 | 简单、稳定，保持总路由权重 |
| B：功能投影 | 学习式 row-softmax | 固定的校准标量 | 同时处理方向匹配与输出幅度差异 |
| C：条件投影 | 学习式 row-softmax | 校准标量加有界、token 条件的残差 | 进一步适应不同输入，需更多校准与正则 |

版本 A 满足：

$$
\alpha_j\ge0,\qquad
\sum_{j\in P}\alpha_j=\sum_{i\in A}g_i.
$$

版本 B/C 的标量可能带符号，系数和也可能改变。这时 $\alpha$ 是重构系数，不能再解释为概率；强制 softmax 或重新归一化会改变重构目标。

该结构有一个有用性质：当 $A\subseteq P$ 时，$M$ 为空，直接恢复原生输出；多预取的专家权重为零。第一版可以保留这一性质，以降低学习难度。进一步允许命中贡献也被调整，可能提高某些 miss 场景的拟合能力，但应作为独立消融。

### 3.2 分配分数的轻量参数化

一种实现选择是：

$$
s_{ij}
=a_i^\top b_j+
\operatorname{MLP}_\phi\!\left(
p_i,q_i,p_j,q_j,q_i-p_i,q_j-p_j,u
\right)
-\kappa\ell_{i\to j}.
$$

$a_i,b_j$ 编码有方向的专家关系，$\ell_{i\to j}$ 是可选的校准损失。精确排序得到的 rank 可作为特征，但其排序本身仍是离散操作；若希望保留更直接的梯度，可先使用连续分数和 margin。

只为 $i\in M,j\in P$ 计算该模块。小 embedding/MLP 下，关系计算规模约为 $O(K_0K_pr)$，其中 $r$ 表示小特征宽度。实际延迟、参数读取和归约开销需要测量。

### 3.3 为什么不直接固定双边 OT 边缘

若采用标准平衡 OT，既固定源边缘为遗漏权重 $g_M$，又固定目标边缘为由预取分布得到、总质量与 $g_M$ 相同的 $b$：

$$
\Gamma\mathbf1=g_M,\qquad\Gamma^\top\mathbf1=b,
$$

再用列和决定补偿权重，那么结果已经被约束为 $b$。改变专家间代价可能改变传输路径，却无法改变最终目标权重。尤其当补偿只保留标量质量、没有源目标相关的投影时，这会失去所需的权重适应能力。

更合适的起点是仅约束源质量、让目标边缘自由：

$$
\min_{\Gamma\ge0,\ \Gamma\mathbf1=g_M}
\langle\Gamma,D_\phi\rangle
+\tau\sum_{i,j}\Gamma_{ij}\log\Gamma_{ij}.
$$

此时各行的解是基于代价的 softmax 分配，等价于 $\Gamma_{ij}=g_iT_{ij}$。可以对目标列和增加软正则，例如鼓励接近真实分数限制到 $P$ 后的基线权重，但不应把预取概率硬性规定为最终列和。

这是一种可学习的质量分配参数化；它是否有效，应由最终聚合输出损失决定，而不是仅由传输代价大小决定。

## 4. 联合训练的关键：连续权重与离散集合有两条梯度路径

### 4.1 固定集合时，重构模块可以直接反向传播

离线计算 $A\cup P$ 中专家的输出，在局部训练中把这些向量当成常量：

$$
\mathcal L_{\mathrm{rec}}
=\frac{\|Y_P\alpha_\phi-y^\star\|_2^2}
{\|y^\star\|_2^2+\epsilon}.
$$

权重梯度为：

$$
\frac{\partial\mathcal L_{\mathrm{rec}}}{\partial\alpha}
=\frac{2Y_P^\top(Y_P\alpha-y^\star)}
{\|y^\star\|_2^2+\epsilon}.
$$

所以基模参数可以冻结，专家输出也可在无梯度模式下获得，再在有梯度的作用域内计算 $\alpha$ 和加权输出。原专家输出只在训练时提供监督；推理时不能先执行 miss 专家再决定如何替代它。

只要 $\alpha_\phi$ 使用未 detach 的 $p_\theta$，重构损失也会传回 prefetch router 的连续输出。这是有效的联合训练路径，但它暂时把集合 $P$ 当成固定。

### 4.2 让重构目标参与集合选择，需要单独处理离散性

硬 top-k 的成员随 logits 变化是分段常数。若训练只使用已选专家输出，模型不会自动得到“换入某个未选专家，重构会改善多少”的梯度。连续更新仍可能间接改变排序和集合，但这不是对换入、换出收益的明确估计。

因此要分别检查：

- **权重路径：** $\mathcal L_{\mathrm{rec}}\to\alpha\to p_\theta$；
- **集合路径：** $\mathcal L_{\mathrm{rec}}\to P_\theta$。

仅看到 prefetch router 参数有非零梯度，不足以证明集合选择已被有效优化。

### 4.3 两种可行的集合训练方法

**方法一：连续松弛或 straight-through top-k。**

训练时在候选集合 $\mathcal U$ 上使用可微选择近似，推理时使用硬 top-k。$\mathcal U$ 可以包含当前高分预测候选、原生目标专家及探索候选；原生目标只用于训练中的监督/探索，不得成为推理时提前选择的输入。

需要注意：若希望知道未选候选的加入价值，就必须计算它的输出，或使用有验证依据的输出/收益估计。只执行硬 top-k 专家，再给所有专家挂一个 soft mask，不能凭空得到未选专家的真实输出梯度。限制在小 $\mathcal U$ 上训练可控制成本，但梯度覆盖也只限于这个候选集。

Straight-through 使用的是有偏的梯度估计；soft 训练和 hard 推理的差距必须直接测量。

**方法二：采样硬集合，使用策略梯度。**

由早期 logits 定义无放回抽样策略 $\pi_\theta(P\mid z)$，每次只计算 $A\cup P$ 的专家。损失梯度可估计为：

$$
\nabla_\theta\mathbb E_{P\sim\pi_\theta}\mathcal L(P,\theta,\phi)
=
\mathbb E\left[
\nabla_\theta\mathcal L\big|_P+
(\mathcal L-b(z))\nabla_\theta\log\pi_\theta(P\mid z)
\right].
$$

第一项是固定集合的连续路径，第二项使低重构误差的集合更可能被选择。基线 $b(z)$ 用于降方差。这条路线无需每步运行全部专家，但采样方差、探索范围以及随机训练到确定性 top-k 推理的差距需要处理。

建议先做“固定 predictor 训练重构器”，再以小候选连续松弛进行联合原型；若专家输出采集成本过高，再比较硬集合采样。两者都应保留同预算的 hard-top-k 验证。

### 4.4 补偿感知的集合搜索与解析删除代价

对一个已经训练或校准的补偿器，定义其在集合 $P$ 上的实际重构误差：

$$
J_\phi(P;x)=
D\!\left(y^\star,Y_PF_\phi(p,q,P,x)\right).
$$

从候选集 $\mathcal U$ 开始，每次删除补偿后误差增加最小的专家：

$$
j^\star=\arg\min_{j\in P}
\left[J_\phi(P\setminus\{j\};x)-J_\phi(P;x)\right],
\qquad P\leftarrow P\setminus\{j^\star\},
$$

直到达到预算。每个候选删除都要按新的集合重新运行补偿器；对固定权重直接删除一个输出，衡量的是未补偿损失。也可采用逐个加入或固定预算的一入一出交换，每次按新的补偿结果评价整个集合。上述搜索是启发式，通常没有全局最优保证；有限能力的学习式补偿器甚至可能不满足误差随集合增大而下降。

线性重构提供了一个可解释的解析版本。令：

$$
J_\lambda(P)=\min_\alpha
\|Y_P\alpha-y^\star\|_2^2+\lambda\|\alpha\|_2^2,\qquad
H_P=Y_P^\top Y_P+\lambda I,\qquad
\alpha^\star=H_P^{-1}Y_P^\top y^\star.
$$

当 $\lambda>0$、系数可自由取实数时，删除专家 $j$ 并重新优化其余权重的目标增量恰为：

$$
\boxed{
J_\lambda(P\setminus\{j\})-J_\lambda(P)
=\frac{(\alpha_j^\star)^2}{(H_P^{-1})_{jj}}
}.
$$

这是同一个二次目标增加约束 $\alpha_j=0$ 的结果。分子描述该专家当前系数大小；分母还包含它与其余输出的相关关系。因此，仅看 gate 或系数大小并不能得到这个删除代价。该式比较的是含正则的完整目标；非负、保总质量或保留命中系数等约束需要求解相应约束问题，不能直接套用该式。

**信息可用性。** 精确计算上式需要候选专家输出，适合作为离线 oracle 和训练教师。在线为剪枝先执行全部候选会消耗本想节省的专家计算；预取时还没有当前 token 的真实路由和输出。部署可采用两条路径：

- 当前 token 剪枝：用校准或条件预测的 Gram 矩阵近似 $Y^\top Y$，结合当前真实稀疏权重评价重构代价；需验证误差排序是否可靠。
- 提前一个 token 预取：用离线集合搜索产生的误差、集合或交换收益监督早期选择器，或训练仅以早期信息为输入的集合误差预测器。

若采用固定 Gram 近似，令 $w$ 为原生稀疏权重、$\alpha$ 在全集上以零扩展，则：

$$
\|Y\alpha-Yw\|_2^2
=(\alpha-w)^\top(Y^\top Y)(\alpha-w)
\approx(\alpha-w)^\top\widehat H(\alpha-w).
$$

这保留了专家残差的交叉项。$\widehat H$ 应保持半正定，并在真实选择分布上校验；稀疏专家对统计简单拼接不自动保证这一性质。对预取，当前 $w$ 只能提供训练监督，早期集合误差预测需学习给定前一 token 信息的条件期望。

用 oracle 最优权重选出的集合还应交给实际 $F_\phi$ 验证：若教师依赖的重构能力超出部署补偿器的表达能力，集合标签可能难以兑现。可交替训练补偿器与选择器，逐步按实际补偿器刷新候选集合的代价。存在多个等价好集合时，用相对误差或集合排名监督通常比强制模仿一个任意集合更合适。

### 4.5 让选择掩码进入 substitutor 的分配过程

一种直接连接集合梯度的结构是在候选集合 $\mathcal U$ 上生成掩码：

$$
m=\operatorname{SoftTopK}_{K_p}(r_\theta(z)),\qquad
0\le m_j\le1,\qquad \sum_{j\in\mathcal U}m_j=K_p.
$$

$r_\theta$ 是前一 token 的选择 logits；候选外 $m_i=0$。推理使用硬 top-k 掩码，训练可用连续松弛或 straight-through 估计。让这个掩码直接决定补偿贡献的分配：

$$
T_{ij}(m)=
\frac{m_j\exp s_{\phi,ij}}
{\sum_{b\in\mathcal U}m_b\exp s_{\phi,ib}},
\qquad i\in A,\ j\in\mathcal U,
$$

$$
\boxed{
\alpha_j(m)=
m_jg_j+
\sum_{i\in A}g_i(1-m_i)T_{ij}(m)c_{\phi,ij}
},
\qquad
\hat y(m)=\sum_{j\in\mathcal U}\alpha_j(m)E_j(x).
$$

这里 $g_j=0$ 对所有非原生选中专家成立。硬掩码下，选中原专家保留原贡献，遗漏贡献被分给选中候选；未选候选最终权重为零。当全部原专家都被选中时，恢复原生输出。若 $c_{ij}=1$，连续掩码下也保持原生总权重。

选择掩码同时控制三件事：保留多少原贡献、哪些贡献需要替代、哪些目标可以接收替代贡献。改变某个 $m_j$ 会改变其他专家分得的补偿权重。因此，重构损失传回选择器时，可以衡量“把这个专家加入集合后，整个补偿结果会怎样变化”。

训练时，$s_{\phi,ij}$ 与 $c_{\phi,ij}$ 可使用当前真实路由和廉价当前特征；$r_\theta$ 只能使用前一 token 已知信息。后到信息通过损失监督早期选择，而不进入预取时的前向输入。

该结构仍受第 4.3 节的信息和离散性约束：为了获得候选换入收益的输出梯度，训练时需要计算 $\mathcal U$ 的输出，或使用验证过的代理。连续掩码可能利用超过 $K_p$ 个非零专家，应检查硬 top-k 下的表现；straight-through 是有偏梯度估计。部署只执行硬掩码选中的专家。

### 4.6 推荐验证顺序

先固定一种补偿器，对小候选集合比较 gate 排序与补偿后误差搜索，确认“选择规则改变”确实有收益；再训练轻量 substitutor 接近固定集合的可补偿上限；最后采用掩码参与分配的结构联合优化早期选择器。

| 选择器 | 补偿器 | 作用 |
|---|---|---|
| 路由 KL 训练、硬 top-k | 静态投影 | 初始组合基线 |
| 同一个选择器 | 可学习 substitutor | 测量权重和补偿的收益 |
| 补偿误差监督的选择器 | 同一可学习结构 | 测量集合选择的新增收益 |
| 补偿误差联合训练 | 同一结构、明确优化集合梯度 | 测量联合适配的收益 |
| 离线集合搜索与最优权重 | 解析 oracle | 估计当前候选预算的可达空间 |

比较应固定候选和执行预算，并同时报告实际学习式补偿误差与 oracle 误差。通用的稀疏重构、子集选择和补偿感知剪枝已有成熟思想；本方案的研究主张应落在 MoE 的一 token 因果预取、后到路由条件补偿、功能冗余驱动的集合学习及真实部署收益。

## 5. 训练目标与推荐日程

### 5.1 主目标

$$
\mathcal L
=\mathcal L_{\mathrm{rec}}
+\lambda_{\mathrm{route}}D_{\mathrm{KL}}(\bar q\Vert p_\theta)
+\lambda_{\mathrm{coef}}\mathcal R(\alpha,c).
$$

$\bar q$ 是按模型实际分数构造的路由蒸馏目标；$\mathcal R$ 可以限制系数过大、条件投影偏离校准值或权重过度集中。KL 项保留原生路由先验，重构项则允许具有良好补偿能力的替代集合。

后续加入全模型 logits 蒸馏或任务 NLL，检验局部重构改善能否传递到任务精度。仅有局部输出 MSE 不能保证端到端质量。

一个完整训练目标可写成：

$$
\mathcal L_{\mathrm{joint}}
=\sum_l\lambda_l\mathcal L_{\mathrm{rec},l}
+\lambda_{\mathrm{KD}}\mathcal L_{\mathrm{logit\text{-}KD}}
+\lambda_{\mathrm{route}}\mathcal L_{\mathrm{route}}
+\lambda_{\mathrm{coef}}\mathcal R.
$$

其中 logits 蒸馏以独立原模型为 teacher；局部重构可以使用同一学生状态上的原生 MoE 作为局部 teacher。两种监督参照需明确区分。训练初期可以保留较强的路由监督，之后扫描较弱系数或去掉该项作为消融，让重构收益决定偏离原生集合是否值得。路由 recall 下降而任务质量提高，是这个目标允许并需要检验的结果。

当 $K_p$ 固定且所有专家同大小时，简单惩罚预取专家数是常量，不能产生有意义的选择信号。系统成本项需要依赖实际 cache miss、字节、到位概率或可变预算，再纳入训练。

联合优化之后，$p_\theta$ 可能更接近“有利于重构的集合优先级”，而非校准良好的原生专家需求概率。若下游需要概率解释，应单独测校准，或分开需求预测头与集合选择头。

### 5.2 四阶段训练

| 阶段 | 训练对象 | 目的 |
|---|---|---|
| 1. 原生路由蒸馏 | prefetch router | 获得稳定、较高覆盖的初始集合 |
| 2. 固定集合生成器 | 重构模块 | 验证同一个 $P$ 上，学习权重能否超过真 gate 重归一化、OWA 和静态投影 |
| 3. 联合优化 | prefetch router + 重构模块 | 让预取集合偏向容易重构的专家组合，明确处理集合梯度 |
| 4. 轨迹适配 | 两个模块，基模保持冻结 | 在实际替代产生的状态和真实 decode 上校验并适配误差累积 |

局部训练中的 teacher 输出应 stop-gradient。全模型训练需要允许梯度穿过冻结的后续算子传向重构权重；“冻结参数”与“整段 forward 使用 no_grad”是不同操作，尤其要核对量化后端的输入反向能力。

先在固定 teacher 轨迹训练便于调试；之后需要刷新由当前策略产生的 hidden states 和 miss 分布，否则 predictor 与 substitution 共同改变轨迹带来的偏移可能抵消收益。

## 6. 先估计集合的可补偿上限，再判断模块是否值得做

固定预取集合 $P$，离线求两个 oracle：

1. **非负、保总质量重构：**

   $$
   \min_{\alpha\ge0,\ \mathbf1^\top\alpha=\sum_{i\in A}g_i}
   \|Y_P\alpha-y^\star\|_2^2.
   $$

2. **带正则的有符号重构：**

   $$
   \min_\alpha\|Y_P\alpha-y^\star\|_2^2+
   \lambda\|\alpha-\alpha_0\|_2^2.
   $$

第二个问题可用小规模线性求解得到：

$$
\alpha^\star=
(Y_P^\top Y_P+\lambda I)^{-1}
(Y_P^\top y^\star+\lambda\alpha_0).
$$

实现时用稳定的线性求解，不必显式求逆。Oracle 依赖训练时的真实原专家输出，只用于评价固定集合的可补偿空间和生成监督，不能直接部署。

结果可以区分三种瓶颈：

| 观察 | 更合理的下一步 |
|---|---|
| Oracle 很好，学习模块较差 | 提高功能特征和条件权重模型的表达能力，改进训练分布 |
| 非负 oracle 较差，有符号 oracle 好 | 引入受约束的标量投影或带符号重构 |
| 两种 oracle 都较差 | 改进预取集合、增大预取预算，或增加受预算约束的输出补偿能力 |

可微性带来的是优化手段。只有预取专家输出具有足够的表示能力、梯度估计有效、训练分布匹配部署，精度才有机会稳定提高。

## 7. 基线、消融与研究增量

### 7.1 权重基线必须固定同一个预取集合

比较以下方案，并固定 $P$、量化与执行器：

- 预取分布在 $P$ 上的权重；
- 当前真实 gate 在 $P$ 上取分数并按原模型规则归一化；
- CommitMoE 风格的命中贡献增强和整体缩放；
- ExFold 风格的静态方向性标量映射；
- 可学习的 $F_\phi(p,q,P)$；
- 离线 oracle 重构。

随后固定模块结构，再比较 KL-only predictor、只有连续权重路径的联合训练、含集合优化的联合训练。这样才能分辨收益来自权重还是预取集合。

### 7.2 条件信息消融

| 输入/设计变化 | 检验的问题 |
|---|---|
| 只用 $q$，与同时用 $p,q$ 比较 | 早期概率除确定集合以外，是否还有实际价值？ |
| 匿名排序概率，与保留专家身份比较 | 是否确实需要专家功能关系？ |
| 静态专家对，与加入 $x/z$ 特征比较 | 替代关系是否显著依赖 token？ |
| 固定标量，与条件标量比较 | 幅度校正能否在相同计算预算下获益？ |
| 固定 $P$，与联合更新 $P$ 比较 | 重构损失是否真正改善预取集合？ |
| 本层输出 MSE，与全模型蒸馏比较 | 局部改善能否传递到任务精度？ |

其中“$p,q$ 同时输入是否优于只用 $q$”尤其重要：一旦 $P$ 已固定，$p$ 不必然包含额外有用信息。它可能提供早期状态线索，也可能只是噪声，应该由实验回答。

### 7.3 相对已有方法的具体推进

CommitMoE 已有预测集合执行与手工 OWA，ExFold 已有方向性投影；SERE 提供输出相似关系。因此，可研究的增量应明确为：

> 提前一个 token 选择用于重构的专家集合，以当前真实路由为后到的条件信号，在该集合内学习 token 条件的贡献重分配与补偿，并让输出重构或端到端蒸馏损失通过明确的集合优化机制反馈到 prerouter。

核心证据应是相同预取预算和推理开销下，端到端质量–时延优于这些强基线，而不只是训练损失更低。该表述是待验证的研究主张，不等于已确认独有的算法。

### 7.4 同时对齐预测时间线、专家预算和补偿能力

| 比较 | 固定条件 | 回答的问题 |
|---|---|---|
| CommitMoE 原时间线与一 token lookahead | predictor 容量尽量对齐，报告实际窗口、字节与状态信息 | 额外提前量如何影响预测误差与暴露等待？ |
| 同一 token lookahead：真 gate、OWA、静态投影、可微替代器 | 同一预测集合、执行预算与后端 | 精度提升是否来自重分配和补偿？ |
| 固定替代器结构：路由监督与联合训练 | 相同预算、候选探索与训练数据 | 是否选到了更易重构的专家组合？ |
| 不同 $K_p$ 的质量–时延曲线 | 相同硬件、量化、缓存与输入负载 | 功能冗余能转化为多少加载或计算节省？ |

ExFold 的静态方向性投影适合作为相同预取集合上的补偿基线；使用预取集合替换它原有保留集合时，应标记为移植基线。其 P4+D64 将 prefill 每 token 数和 decode batch 专家池分别约束，不能与每 token TopK=4 视为相同 decode 计算预算。详细原文核验见[综述 ExFold 小节](moe_expert_substitution_prefetch.md)。

建议首轮采用三个判据：固定集合的学习补偿明显接近 oracle；联合训练在相同 $K_p$ 下进一步改善 hard-top-k 重构与任务质量；真实执行中 substitutor 和预测器的额外开销小于节省的等待。三者分别检验可补偿性、集合优化和系统收益。

## 8. 与当前工程的接口

截至本文核对时：

- [routing.py](../../prefetch/prerouter/routing.py) 已实现“预测分数选择 ID，当前原生 gate 提取权重并归一化”的基线；预测分数在选择处被 detach。
- [structure.py](../../prefetch/backbone/structure.py) 将选择分数定义为 sigmoid 分数加 correction bias；它与实际混合权重需要继续分开。
- [patch.py](../../prefetch/prerouter/patch.py) 收集原生路由并执行预取分支，适合接入后到的条件重构模块。
- [train.py](../../prefetch/training/train.py) 的 router 阶段在 no_grad 下执行基模，再在外部计算路由 KL；当前没有由 MoE 输出重构产生的训练目标。

局部原型需要增加三类接口：输出采集器记录 $A\cup P$ 的专家输出；重构模块输出专家 ID 与 $\alpha$；训练器计算输出重构损失并管理连续/集合两条优化路径。全模型蒸馏阶段还要调整梯度作用域并验证量化后端。

实现评估应先覆盖局部重构与 hard-top-k 验证，再接入全模型蒸馏和实际预取时间线。
